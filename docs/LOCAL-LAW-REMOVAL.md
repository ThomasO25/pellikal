# LOCAL-LAW-REMOVAL.md

Record of removing Local Law 97 from the public Pellikal website.
**Date:** 24 August 2026

Local Law 97 is no longer presented as a Pellikal service or focus. Every
visible reference has been removed. The old URL still works — it forwards to
`/commercial/` so previously indexed links do not break.

## Old URLs — how they are handled

Neither address 404s.

### `/local-law-97/`
`local-law-97/index.html` is now a **minimal redirect page**:

- `<meta http-equiv="refresh" content="0; url=../commercial/">`
- `location.replace("../commercial/")` for instant client-side redirect
- `<link rel="canonical" href="https://www.pellikal.com/commercial/">`
- `<meta name="robots" content="noindex, follow">`
- A plain clickable "Commercial Window Film" link as a no-JavaScript fallback
- **No marketing copy, and no explanation of Local Law 97**
- No header, footer or GTM container (it is not a page visitors stay on, and a
  tracked pageview here would be meaningless)

### `/local-law-97.html`
The legacy flat URL. Regenerated by `tools/build.py` to point at
`/commercial/` rather than at itself, via the `redirectTo` setting in
`site.config.json`.

## Configuration

In `site.config.json` the page entry is now:

```json
{ "slug": "local-law-97", "file": "local-law-97/index.html",
  "inSitemap": false, "priority": "0.0",
  "redirect": true, "redirectTo": "commercial", "partials": false }
```

- `inSitemap: false` — excluded from `sitemap.xml`
- `redirectTo: "commercial"` — the old `.html` URL forwards to `/commercial/`
- `partials: false` — no header/footer are injected
- It is also listed in `analytics.excludeFromTracking`

## Note on search results

Google may keep showing the old Local Law 97 result for a short period until it
recrawls. The `noindex, follow` and canonical tags tell it to drop the page and
pass its value to `/commercial/`. Resubmitting `sitemap.xml` in Search Console
speeds this up. No action is needed beyond that.
