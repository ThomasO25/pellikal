## 3. Explicitly NOT claimed

None of the following appears anywhere, and none may be added without written
documentation:

- "LLumar certified master installer"
- "LLumar's #1 dealer" / "top" / "leading" / "highest rated"
- "Exclusive Hamptons installer" / "preferred East End installer"
- "LLumar guarantees our workmanship"
- Certification standards, training requirements or vetting criteria for the
  SelectPro programme
- Any award, endorsement or recommendation by LLumar
- Any LLumar performance figure other than item 7/9 above

## 4. Trademark handling

- First prominent use per page carries the symbol: **LLumar®**, **SelectPro™**
- Symbols are not repeated in every sentence
- The site never implies Pellikal owns or controls the LLumar marks
- No competitor marks (Vista, FormulaOne, 3M, SunTek) appear anywhere
